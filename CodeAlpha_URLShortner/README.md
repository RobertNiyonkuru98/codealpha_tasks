# URL SHORTNER CODE TASK

This project is comprised of code logics that will allow one to shorten a long url to a short.
the tasks are as follows:

1. Creation of a backend server using express
2. Creating the database using postgresql
3. Creating an API endpoint that will allow one to accept long URLs, generate a unique short code
4. Store the long url and the short code in the database
5. Create an API endpoint that will allow one to redirect the short code to the long url
6. Connect the backend server to the database and
7. Connect basic frontend to the backend server
